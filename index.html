02ClariFlowAI & browser tools

Finding the missing question in a meeting

I built a Chrome extension that reads meeting transcripts, identifies ambiguous requests, and tracks how stakeholder answers change the requirements. Each refined requirement links back to its source.

Example: “We need an export” prompts “Which file format?” An answer of “PDF” gives the team a requirement it can test.

JavaScript · Manifest V3 · OpenAI · Gemini
